なぜ、そう言い切れるのか

「安全です」という主張ではなく、構造としてそうなっています。

1そもそも本文を取得する処理が存在しません

LeakScanがGmailで行うのは検索の実行だけです。Gmailの検索結果の一覧画面には、 件名の断片は出ても本文は表示されません。拡張機能が読み取るのは、その一覧の行に埋め込まれた 差出人のアドレスと表示名の属性値だけです。

メールを開く処理も、本文を取得する処理も、コードとして書かれていません。 「読まないようにしている」のではなく、読む機能がありません。

確認方法: ソース内で本文取得に使う API を検索しても、該当箇所は0件です。

2データを送信するコードが1行もありません

通信は1種類だけです。このサイトから漏洩データの一覧（静的なJSONファイル）を ダウンロードする通信のみで、そのリクエストにあなたの情報は一切含まれません。 URLは固定で、パラメータも付きません。

アップロードする処理そのものが存在しません。 送信先となるサーバーを我々は持っておらず、受け取る口がありません。

確認方法: Chromeの開発者ツール（F12）のネットワークタブを開いたままスキャンを実行すると、発生する外部通信が breaches.json の取得だけであることが見えます。

3Googleアカウントの認証情報を預かりません

多くの類似ツールはGmail APIを使い、OAuthであなたのアカウントへのアクセス権を取得します。 その場合、事業者側にアクセストークンが保管され、それが漏れればメールを読まれます。

LeakScanはGmail APIを使いません。あなたが既にブラウザで開いているGmailの画面を、 そのまま見るだけです。アクセス権を受け取らないので、漏れる資格情報が存在しません。 連携の確認画面が出ないのはこのためです。

4Chromeに要求している権限が最小です

拡張機能は、インストール時にChromeが権限を表示します。LeakScanが求めるのは storage（結果の保存）と、mail.google.com および このサイトへのアクセスだけです。

「すべてのウェブサイトのデータを読み取る」権限は要求していません。 したがって、Gmail以外のサイト（ネットバンキング、SNS、業務システムなど）の内容を LeakScanが見ることは、Chromeの仕組み上できません。

確認方法: chrome://extensions でLeakScanの「詳細」を開くと、許可されている権限の一覧が確認できます。

5結果はあなたのブラウザから出ません

スキャン結果は、Chromeが拡張機能ごとに用意する保存領域に置かれます。 この領域は同じブラウザの同じプロフィールからしか読めません。 他の端末にも同期されず、我々も閲覧できません。

設定画面の「スキャン結果を削除する」でいつでも消せます。拡張機能ごと削除すれば、 保存領域も一緒に消えます。

6何をしているか、全て公開しています

拡張機能のソースコードは JavaScript 約1,200行、外部ライブラリは 1つも使っていません。依存パッケージがないということは、 この1,200行を読めば、動作の全てが分かるということです。

難読化も圧縮もしていません。配布しているzipの中身と、GitHubで公開しているコードは同一です。

我々を信用していただく必要はありません。

  1. 通信を見る スキャン実行中に F12 → ネットワークタブ。外部への通信が leakscan.matsunai.com からのダウンロード1件だけであることを確認できます。

よくある質問

本当に無料？

無料です。課金の仕組みがありません。登録もメールアドレスの入力も不要です。

メールを読まれない？

件名も本文も読みません。検索結果の一覧に出る差出人だけを見て、あなたのパソコンの中で照合します。

該当が出たら何をすれば？

やるべきことが優先順位つきで結果画面に出ます。パスワードが漏れたなら変更、カードなら明細確認、メールアドレスだけなら偽メールに警戒、が目安です。

「該当なし」なら安心？

いいえ。別のアドレスで登録したサービスは見つけられません。安全の証明ではありません。

やめたいときは？

Chromeから削除すれば、結果ごと完全に消えます。
