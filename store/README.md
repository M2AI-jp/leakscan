## 貼り付け用テキスト

### 拡張機能名（最大75文字）

```
LeakScan — 情報漏洩チェッカー
```

### 概要 / Short description（最大132文字）

```
Gmailの差出人を国内の公表済み情報漏洩事案と照合し、あなたが使っているサービスの漏洩だけを表示します。メール本文は読まず、外部送信もありません。
```

### 詳細 / Detailed description

```
LeakScanは、あなたが使っているサービスのうち、どれが情報漏洩を公表したかを調べる無料のツールです。

■ 何をするか

ボタンを1回押すと、Gmailの検索機能を使って、漏洩を公表した企業からのメールが届いていないかを確認します。届いていれば、あなたはそのサービスを使っている可能性が高く、その漏洩はあなたに関係があります。

結果として、次の2つを表示します。

・何が漏れたのか（メールアドレスだけか、クレジットカードや口座情報までか）
・あなたが今すべきこと（優先度つき）

■ プライバシー

・メールの件名・本文・添付ファイルは読みません。検索結果一覧に表示される差出人の名前とアドレスのみを参照します
・取得した情報を外部に送信しません。照合はすべてブラウザ内で完結します
・Gmail APIもOAuthも使いません。Googleアカウントの連携やパスワード入力は不要です
・スキャン結果はブラウザのローカル保存領域にのみ保存され、開発者が閲覧することはできません
・アクセス解析、広告、トラッキングは一切ありません

■ 収録データ

2026年に日本で公表された情報漏洩事案を収録しています。各事案には出典を明記し、「漏洩を確認」「漏洩の可能性」「調査中」を区別しています。データは毎日更新されます。

データセットはCC BY 4.0で公開しており、誰でも取得・再利用できます。
https://leakscan.matsunai.com/data/breaches.json

■ ソースコードについて

本拡張機能のコードは生成AIにより作成されたもので、人間による詳細なコードレビューを経ていません。動作・内容・安全性についていかなる保証も行いません。

その代わり、ソースコードは全文を公開しています。JavaScript約1,200行、外部ライブラリは一切使用していません。難読化も圧縮もしていないため、配布物とGitHub上のコードは同一です。ご自身で検証したうえでご利用ください。
https://github.com/M2AI-jp/leakscan

■ 注意点

・「該当あり」は、そのサービスを利用していた可能性が高いことを示すもので、あなた個人のデータが流出したことを意味しません。対象かどうかは各社の公式発表でご確認ください
・「該当なし」は安全の証明ではありません。別のメールアドレスで登録したサービスや、メールが届いていないサービスは検出できません
・Gmail（mail.google.com）専用です

■ 運営

https://leakscan.matsunai.com
```

## 権限の正当化（審査で必ず聞かれます）

申請フォームの「権限の justification」欄に、以下をそのまま記入してください。
**ここが弱いと審査で落ちます。** Gmailを操作する拡張機能は特に厳しく見られます。

### `storage`

```
漏洩事案データのキャッシュ、ユーザー設定（対象アカウント番号など）、およびスキャン結果の保存に使用します。保存先はchrome.storage.localのみで、外部への送信は行いません。
```

### ホスト権限 `https://mail.google.com/*`

```
本拡張機能の中心的な機能のために必要です。ユーザーが明示的に「スキャン開始」を押したときのみ、Gmailのタブを開いて同サービスの検索機能を実行し、検索結果一覧に表示される差出人のメールアドレスと表示名のみを読み取ります。

メールの件名、本文、添付ファイルにはアクセスしません。これらを取得するコードは実装されていません。読み取った差出人情報は、拡張機能に同梱された漏洩事案データとユーザーのブラウザ内で照合され、外部に送信されることはありません。

Gmail APIおよびOAuthは使用しておらず、ユーザーの認証情報を取得・保持しません。
```

### ホスト権限 `https://leakscan.matsunai.com/*`

```
漏洩事案のデータセット（静的なJSONファイル）を取得するために使用します。取得は読み取り専用のGETリクエストのみで、ユーザーを識別する情報やリクエストパラメータは一切含みません。このドメインへのデータ送信は行いません。
```

### ホスト権限 `https://raw.githubusercontent.com/M2AI-jp/leakscan/*`

```
上記と同一のデータセットを、本拡張機能のソースコードを公開しているリポジトリから取得するために使用します。データセットは毎日このリポジトリで更新されるため、配信サーバーの更新が遅れている場合にこちらの新しいデータを使用します。パスは当該リポジトリ配下に限定しています。取得は読み取り専用のGETリクエストのみで、ユーザーを識別する情報やリクエストパラメータは一切含みません。このドメインへのデータ送信は行いません。
```

チェックボックス3点（すべて該当します）:

- [x] 承認された用途と関係のない第三者へのデータ販売・譲渡を行わない
- [x] 本拡張機能の主要機能と関係のない目的でデータを使用または転送しない

> Chrome ウェブストアの定義における「収集」には該当しません。

## 審査で指摘されやすい点と、こちらの立場

| 想定される指摘 | 回答 |
|---|---|
| Gmailへの広範なアクセス権が必要な理由 | 中心的機能そのものであり、ユーザーの明示的な操作時のみ実行。読み取り対象は差出人のみ |
| 権限が機能に対して過大ではないか | `storage` と3つのホストのみ（Gmailとデータ取得先2つ）。`<all_urls>` や `tabs` は要求していない |
| リモートコードの実行 | なし。取得するのはJSONデータのみで、コードの取得・実行は行わない |
| 難読化されたコード | なし。全ソースをGitHubで公開 |
| 単一目的ポリシー | 単一目的（情報漏洩の照合と通知）に限定 |

## 申請後

- 審査は通常数日〜2週間程度です
- 差し戻された場合、理由は具体的に示されます。[Issue](https://github.com/M2AI-jp/leakscan/issues) に貼っていただければ対応します
- 公開後は、サイトのインストール手順を「ウェブストアから1クリック」に差し替える必要があります
  （`site/index.html` の「使い方」セクション）
